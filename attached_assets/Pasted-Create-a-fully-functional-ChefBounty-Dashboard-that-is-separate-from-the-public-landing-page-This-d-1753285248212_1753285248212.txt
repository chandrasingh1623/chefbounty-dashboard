Create a fully functional ChefBounty Dashboard that is separate from the public landing page. This dashboard is the core application, where signed-in users (either Hosts or Chefs) manage everything. Use a unified layout at /dashboard, with all features conditionally rendered based on the user’s role, which is stored in Supabase metadata as either "host" or "chef".

🧩 Tech Stack & Layout
Route: /dashboard

Layout: Sidebar + Top Header + Main Panel

Styling: Tailwind CSS (modern, clean, light shadows, spacing)

Conditional rendering based on user role

Use Supabase Auth to determine role on login

Apply the site's premium style theme (highlight color: #0a51be)

👥 User Roles
Check Supabase metadata field user.user_metadata.role.

Render the correct dashboard content based on:

"host" → Host dashboard

"chef" → Chef dashboard
